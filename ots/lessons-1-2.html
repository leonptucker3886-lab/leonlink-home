OTS Lessons 1 & 2

Officer Training School — approved lesson plans.

Lesson 1: Standards & First Impressions

Time: 45 min. T-5 arrival check: attendance logged 5 minutes before start.

The 3 standards
  1. On time: 5 minutes early.
  2. Answer directly: answer first, then explain.
  3. Finish what you start: if you can't, say exactly what's blocking you.
  1. Brief: learn the 3 standards and repeat them back.
  2. Demo: one good report, one bad report; name the standard the bad one broke.
  3. Practice: partner reports, correction, switch. Includes blocked-task scenarios.
  4. Check: live check with one planted mistake to find.

Pass: name all 3 standards from memory, give a correct report with no more than one correction, catch the planted mistake. Fail: repeat practice next session.

Lesson 2: Chain of Command & Escalation

Objective: name first and second escalation contacts, recognize when a block must go up the chain, send a correct 3-part escalation within 5 minutes. Time: 45 min. T-5 arrival check: same as Lesson 1.

Rule: Blocked + can't fix it in 5 min = escalate. Every escalation: (1) what's blocked, (2) what you need, (3) when you need it by. Chain: direct supervisor first; no answer in 10 minutes → next leader up, copy the supervisor. Going silent is never an option.
  1. Brief (8 min): the rule, the 3 parts, the chain; tie to Standard 3.
  2. Demo (10 min): going silent (wrong), complaining with no request (wrong), 3-part escalation (right).
  3. Practice (15 min): pairs grade each other on all 3 parts and timing:
    1. Locked out the night before a deadline.
    2. Supervisor silent 10 minutes → next leader, copy supervisor.
    3. Conflicting orders → report both to the higher-ranking leader and ask priority.
    4. Overnight promise blocked at 2200 → escalate by 2205 with partial work.
  4. Check (7 min): surprise block, live escalation; find and fix a planted error.
  5. Close (5 min): name both contacts; instructor logs one fix per recruit.

Pass: all 3 parts, within 5 minutes, planted mistake caught, both contacts named. Fail: repeat Practice. Materials: escalation card, chain-of-command chart, 4 scenario cards, 1 planted-error sample.

Silence is a failure, not a strategy.
