# Team 6 SOP (draft)
Branch: design/master-site only. Never push to main.
No-touch without Leon: wall.html, film-room.html, dating-profile.html, kimber-leon.html.

## Done rule
Done = commit hash + live Vercel URL posted in chat and on the board. "Green" with no commit is an infraction.

## Flow
1. Lead reads tickets.md hourly; acks Inspector cards within 1h, names owners, ships or reassigns within 4h.
2. Batch several pages per commit. Re-send expired approvals immediately.
3. Blocked = take next task. No task waits on more than one person's commit.
4. Small design calls don't wait for Leon; children, money, legality do.
5. Content can be added, never removed. Design only.
6. Every commit gets a preview check and link posted.
7. No status-only, "got it" or "over to Leon" posts. Never say the team is waiting on Leon.
